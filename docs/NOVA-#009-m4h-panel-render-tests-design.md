# NOVA #009 — M4-H 面板渲染测试（typecheck 通过 ≠ 界面正常）

> **状态**：已实现（2026-11-06）
> **对应台账**：DEV-123 ~ DEV-126
> **分支**：`feat/harness-wiring`
> **前置**：[M4-G 实跑验证](NOVA-#009-m4g-runtime-verification-design.md)

## 一、为什么做这件事

### 1.1 上一批的自省

M4-G 我第一次把应用跑起来看，抓到了 i18n 缺 key 与一个 flaky 断言。
但那批也暴露了本批的问题：

> 前几批加了 5 个新 UI 面板（嵌入后端配置 / 技能目录 / 效果统计 / 边际效用 /
> 技能验证）+ 成本卡片 + 接受度列 —— 但**一次都没真的渲染过**。
> typecheck 通过 ≠ 模板能渲染 ≠ 数据能落到界面上。

### 1.2 人工截图不能回归

M4-G 靠人工实跑 + 截图抓到了问题，价值真实。但：

| 人工方式的问题 | 后果 |
|---|---|
| 不可回归 | 下次改模板又坏了，没人知道 |
| 覆盖不全 | 只看了首屏，5 个面板逐个截图成本高 |
| 抓不到「数据没落到界面上」 | 这类问题最隐蔽（结构对、值是空的） |

故要把这批面板的关键渲染面钉成**自动化**测试。

## 二、实现

### 2.1 用真组件，不用 stub

`el-table` 的列内容（`el-table-column` 的 default slot）是**按行**渲染的 ——
stub 掉它，表格里的「+50%」「100%」这些值根本不会进 DOM，
测试就只能验到静态文案，验不到「数据真的落到界面上了」。

故用**真 Element Plus** 渲染：验的是真实渲染路径（数据 → 模板 → DOM）。

唯一例外是 `el-tabs` / `el-tab-pane`：它们只渲染**被激活过**的那个 tab，
「今日成本」卡片在默认 tab 下根本不在 DOM 里。改法是 stub 掉 tab 容器
让它渲染所有 pane，其余组件仍用真的。

### 2.2 两份测试守什么

**`tests/unit/skills-m4-panels.test.ts`（10 例）** —— SkillsView 的 4 个面板：

| 用例 | 守什么 |
|---|---|
| 技能目录卡片显示主目录路径与技能数 | 数据落到了界面 |
| 没有额外目录时给出说明（而不是空白） | 不留空卡片 |
| 效果统计显示判定标签的**中文** | 用户看不懂 `insufficient_data` |
| 边际效用显示两组成功率与差值（+50%） | 对比数据真的呈现了 |
| 样本不足时明说「样本不足」而非给差值 | **不给半成品结论** |
| 用户接受度：有信号显示百分比、无信号显示「无信号」而非 0% | 不把「没信号」说成「0% 接受」 |
| 技能验证说明 token 成本翻倍 | 用户有权知情 |
| 未选技能直接拒绝（不白跑模型） | 不做无意义消耗 |
| 开始前必须弹确认，且确认框里说明 token 翻倍 | 成本告知不能省 |
| 空数据时各面板不占位 | 空卡片比没卡片更糟 |

**`tests/unit/m4-panels-settings-cost.test.ts`（8 例）** —— 设置页嵌入后端卡片 + 模型对比页今日成本卡片：

| 用例 | 守什么 |
|---|---|
| 真向量时说「已启用真实向量」 | 状态如实呈现 |
| **伪向量时必须说「召回是噪声」** | 不能装作在用真向量 |
| 测试连接 / 检测本地模型会真的调后端 | 按钮不是死的 |
| 今日费用 + 输入/输出 token 分项 | 成本分项呈现了 |
| 按模型分布显示每个模型花了多少 | 归因信息没丢 |
| 定价设置入口 + 单价表单 | 用户能给自己的模型配价 |

### 2.3 顺带钉住 handler 与组件的形状约定

`insight:cost:today` 真实返回**扁平**结构：

```ts
data: { totalCostUsd, totalTokens, totalInputTokens, totalOutputTokens, byModel, recent, stub }
```

我第一版 mock 写成了 `{ today: {...} }` 嵌套 → 组件读 `todayCost.byModel` 读不到 →
「按模型分布」那栏**测不出来**。

**生产代码是对的**（handler 扁平、组件也读扁平），是 mock 没照契约写。
已对齐 —— 这正是组件测试的价值：它把「handler 与组件的形状约定」钉住了，
今后谁改形状都会红。
